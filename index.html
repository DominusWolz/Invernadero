Conectar Sensores (Wi-Fi / Bluetooth)

Usa el emulador mientras llegan los sensores físicos. Los datos se envían a Firebase Realtime Database para que la migración al microcontrolador sea directa.

  1. Instala el sensor de humedad y temperatura dentro del invernadero.
  2. Enciende el módulo en modo emparejamiento y verifica la red o Bluetooth.
  3. Presiona Conectar Sensor para iniciar la verificación y transmisión.

Error de conexión detectado — Guía de solución:

  • Verifica que el microcontrolador esté alimentado (LED de estado encendido).
  • Si usas Wi-Fi, confirma que la red sea 2.4 GHz y las credenciales sean correctas.
  • Si usas Bluetooth, acércate a menos de 10 metros y reinicia el emparejamiento.
  • Revisa las reglas de escritura en Realtime Database de Firebase.
